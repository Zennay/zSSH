# zSSH Support

For installation questions, bug reports, compatibility issues, and feature requests, use the public GitHub support route:

https://github.com/Zennay/zSSH/issues

For security vulnerabilities, use GitHub's private vulnerability-reporting flow for this repository:

https://github.com/Zennay/zSSH/security/advisories/new

Do not post secrets, capability URLs, bearer tokens, private keys, API keys, MFA/OTP codes, or exploit details in a public issue.

When reporting a problem, include the zSSH version, client type, relevant non-secret configuration, and a redacted error message. Never include authentication material.
