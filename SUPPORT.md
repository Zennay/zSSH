# zSSH Support

For installation questions, bug reports, compatibility issues, and feature requests, use the GitHub repository:

https://github.com/Zennay/zSSH/issues

For security vulnerabilities, do not post secrets, capability URLs, bearer tokens, private keys, or exploit details in a public issue. Use GitHub's private vulnerability reporting/security-advisory flow for the repository when available.

When reporting a problem, include the zSSH version, client type, relevant non-secret configuration, and a redacted error message. Never include authentication material.
